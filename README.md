# 🛍️ Customer Trends Data Analysis

A beginner-friendly project analyzing customer shopping behavior using Python and Pandas.

## 📌 About

This repo contains a Jupyter Notebook that explores a retail customer dataset to understand shopping patterns — spending habits, popular categories, seasonal trends, discount usage, and more.

## 📂 Structure

```
Customer-trends-data-analysis/
├── Customer_Shopping_Behavior_Analysis.ipynb   # Main analysis notebook
├── customer_shopping_behavior.csv              # Dataset
└── README.md
```

## 📊 Data Summary

The dataset contains individual customer transaction records for a retail store, with details such as:

- **Demographics:** Customer ID, Age, Gender, Location
- **Purchase details:** Item Purchased, Category, Purchase Amount (USD), Size, Color, Season
- **Customer feedback:** Review Rating
- **Shopping habits:** Subscription Status, Payment Method, Shipping Type, Frequency of Purchases, Previous Purchases
- **Promotions:** Discount Applied, Promo Code Used

Each row represents one purchase, making it useful for exploring how factors like age, gender, season, and discounts relate to spending behavior.

## 🛠️ Tools Used

- Python 3
- Jupyter Notebook
- Pandas
- NumPy

## 🚀 Getting Started

```bash
git clone https://github.com/kaveri-singh/Customer-trends-data-analysis.git
cd Customer-trends-data-analysis
pip install pandas numpy jupyter
jupyter notebook
```

Then open `Customer_Shopping_Behavior_Analysis.ipynb` and run the cells top to bottom.
